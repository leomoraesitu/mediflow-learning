# Mobile

Aplicativo Flutter Android principal do MediFlow Learning.

## Estado atual

O scaffold inicial foi criado na Aula 7. A aplicação possui uma primeira árvore de widgets composta por `MainApp`, `MaterialApp`, `Scaffold`, `Center` e `Text`, que apresenta a mensagem “MediFlow em construção”.

O fluxo de negócio do Modo Farmácia ainda não foi implementado.

## Execução

Consulte os dispositivos disponíveis, entre no diretório do aplicativo e execute-o informando o identificador desejado:

```bash
flutter devices
cd apps/mobile
flutter run -d <device-id>
```
