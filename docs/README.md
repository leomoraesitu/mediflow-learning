# Documentação

Documentação pública de arquitetura, decisões e contratos do MediFlow Learning.

Todo exemplo documentado deve ser reproduzível com dados sintéticos e sem depender de informações confidenciais. Credenciais, tokens, chaves, dados pessoais e informações médicas reais não devem ser incluídos em textos, diagramas, exemplos de configuração ou registros de execução.

## Architecture Decision Records

`adr/` reúne decisões de arquitetura registradas no momento em que foram tomadas, com o contexto e as consequências aceitas — não uma descrição do estado atual do código (isso é papel dos READMEs de cada package/app).
